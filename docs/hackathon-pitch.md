# Hackathon Pitch

## One-line pitch

India AI Grid is an AI infrastructure decision-intelligence platform that helps companies identify where India's next AI data centres can be built, whether the infrastructure can support them, whether demand exists, and which ecosystem partners are needed.

## Demo flow

20 MW AI inference project
→ SiteFinder
→ India map
→ infrastructure readiness
→ demand intelligence
→ digital twin
→ partner graph
→ preliminary readiness report
